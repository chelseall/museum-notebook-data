# Museum Notebook data

Ready-made catalogue files for the Museum Notebook app: museums, artworks and artists, built from Wikidata (CC0) with image pointers to Wikimedia Commons. No user data is stored here.

- `manifest.json`: the list of files with version, size and checksum.
- Files are rebuilt by a script in the app repository; do not edit by hand.

Facts come from Wikidata (CC0). Short descriptions from Wikipedia are CC BY-SA 4.0 and carry a link to the article. Images are not hosted here.
